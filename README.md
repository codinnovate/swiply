# Swiply

Swiply is a web-based AI social media studio. The repository contains:

- `backend/` — NestJS, MongoDB, S3/CloudFront uploads, social connections,
  publishing, voice profiles, automation, and encrypted personal AI keys.
- `frontend/` — Next.js, Tailwind CSS, Radix/shadcn-style components, Zustand,
  TanStack Query, and React Hook Form.
- `infra/` — Terraform for deployment-owned infrastructure.

Start the backend on port 3000, then start the frontend on port 3001. See
`KEYS_SETUP.md` for deployment and user-key setup, plus each application README
for exact commands.
